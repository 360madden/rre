## Source and proof discipline

The canonical [SC research roadmap](REA-RIFT-SPELLCASTING-ROADMAP-2026-10-27.md) defines **G0** = SHA-bound original bytes, **G1** = API/UI description, **G2** = repeated bounded in-game observations, **G3** = client-native code/dataflow established for the *exact* binary, and **G4** = end-to-end explanation with both G2 and G3 support and declared server-side unknowns. **G3 is not inherently higher evidence for live game state than G2; they measure different things.** A single unverified screenshot or one Lua saved file is not G2. A label or one RVA alone is not G3.

**Universal selection preflight (fail closed):** (1) name current SC/RC task and one falsifiable question; (2) identify source owner and inspect exact committed report/receipt, current Git and Workbridge jobs/assignments; (3) bind the correct build, SHA/size and, for live evidence, fresh process/character/role/source time; (4) preserve old findings and stop repeating parked probes without a *new* discriminator; (5) nominate exactly one bounded first route, expected output and stop condition; (6) use a unique Workbridge job ID and inspect its settled **exit code** if a job is actually required; (7) independent method/reviewer check, source hash/bytes and explicit unknowns before a narrow RRE-only commit. Never turn an unsupported step into a passed gate.

The reference physical-PC **on-disk** target at M1 is `C:\Program Files (x86)\Glyph\Games\RIFT\Live\rift_x64.exe`, 60,493,640 bytes, SHA-256 `1935a05c9db6d468e34e0055014a4a99c1b5afceb1695884e24600f5c20a4be8`. **Recheck the actual target before each new native claim;** matching Lab1 binary bytes allow *static* RVA comparison only, not shared VM/host PID, memory state, character identity or server behavior. Changed/missing SHA => **BLOCKED_BUILD**, not an assumed offset rebasing.
