The M3 current-session negative discriminator was obtained without adding code: a bounded Workbridge read-only file/time/SHA inspection, an existing literal-only RRECollector SavedVariables parser (`tools/read-rrecollector-saved.mjs`), and current read-only Windows window inventory. **Decision:** A new MCP server, persistent job manager, scheduler, native scan wrapper, browser continuation extension, or repeated filename scanner would overlap known capabilities. A new helper is justified later only after a specific, reproducible gap that the existing tools cannot solve, with a focused regression test and exclusive file ownership. This is a **deliberate no-code M4 gate**, not evidence that every future tooling need is solved.
